# VAG Forum

Прогрессивный форум для владельцев автомобилей концерна VAG  
(Volkswagen, Audi, Skoda, SEAT, Cupra и др.).

## О проекте

Площадка для обсуждения ремонта, обслуживания, тюнинга и обмена опытом.  
Сайт в активной разработке, постепенно готовится к продакшену.

Статус
🚧 В разработке. Функционал форума, авторизация и бэкенд наращиваются поэтапно.

### Разделы (сейчас)

- **Главная** — обзор и ключевые блоки
- **Форум** — обсуждения
- **Ремонт** — материалы по ремонту
- **Рейтинги** — оценки / топы

## Стек

| Технология     | Назначение                |
| -------------- | ------------------------- |
| Next.js 16     | App Router, SSR/SSG       |
| TypeScript     | Типизация                 |
| Tailwind CSS 4 | Стили                     |
| Redux Toolkit  | Состояние                 |
| Framer Motion  | Анимации                  |
| Lottie         | Анимированные иллюстрации |
| Lucide         | Иконки                    |

## Архитектура

Частичный **Feature-Sliced Design**:
```bash
src/
├── app/ # роуты и layout (Next.js App Router)
├── screens/ # экраны (home, forum)
├── widgets/ # крупные блоки UI (header, home)
├── entities/ # сущности (карточки и т.п.)
└── shared/ # переиспользуемый UI и утилиты
```
## Запуск

```bash
npm install
npm run dev
```
